# Repository Strategy

## Philosophy

Repositories represent capabilities, not projects.

Each repository owns one capability only.

## Repository Responsibilities

platform-automation

- Reusable GitHub Actions
- Composite Actions
- CI/CD templates
- GitHub governance

platform-infra

- Reverse Proxy
- VM configuration
- Networking
- Certificates

platform-monitoring

- Prometheus
- Grafana
- Alertmanager
- Loki

platform-security

- Vault
- PKI
- Security policies

devops-kubernetes-lab1

- Applications
- Helm
- ArgoCD
- Kubernetes manifests
